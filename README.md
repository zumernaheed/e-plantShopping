# e-plantShopping - Paradise Nursery Shopping Application

Paradise Nursery is a React and Redux Toolkit shopping cart application for an online houseplant store.

## Project features

- Landing page with the Paradise Nursery company name and a Get Started button
- About Us section describing the company
- Product listing with 18 unique houseplants
- Three plant categories with six plants in each category
- Product thumbnail, name, description, and price
- Add to Cart button that disables after the plant is added
- Shared navigation bar on the Plants and Cart pages
- Dynamic cart icon count
- Redux Toolkit cart state management
- Increase and decrease quantity controls
- Delete cart item control
- Per-item total price
- Overall cart total
- Continue Shopping button
- Checkout button with a Coming Soon message

## Technologies

React, Redux Toolkit, React Redux, and Vite.

## Run locally

```bash
npm install
npm run dev
```
